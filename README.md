# היומן השבועי שלי

אפליקציית PWA עצמאית בעברית (RTL) לניהול שבועי במרווחים של 30 דקות, בהשראת טבלת האקסל.

## פרסום ב-GitHub Pages

1. פתחו מאגר GitHub חדש (למשל `weekly-planner`).
2. העלו את **כל ששת הקבצים** שבחבילה לתיקיית השורש של המאגר (לא את תיקיית `weekly-planner` עצמה).
3. ב-GitHub פתחו **Settings → Pages**.
4. תחת **Build and deployment**, בחרו **Deploy from a branch**, ענף `main`, תיקייה `/(root)` ולחצו Save.
5. לאחר הפרסום הכתובת תהיה בדרך כלל `https://USERNAME.github.io/REPOSITORY/`.

אין צורך בשרת, בבסיס נתונים, בחשבון משתמש או ב-GitHub Actions. נתוני היומן נשמרים ב-localStorage **בדפדפן ובמכשיר שבו הזנתם אותם בלבד**. הם אינם מסתנכרנים בין מכשירים. מחיקת נתוני האתר עלולה למחוק את היומן, ולכן יש לבצע ייצוא גיבוי JSON תקופתי. ייבוא מחליף את כל הנתונים המקומיים.

## יכולות
- ימים ראשון–שבת, משבצות של 30 דקות מ-06:00 ועד 01:00 למחרת (38 משבצות ליום).
- תכנון וביצוע בפועל בשתי טבלאות נפרדות; עריכת משבצת, מחיקה והעתקת תוכן מהתכנון לביצוע.
- מדדים יומיים, ממוצעים שבועיים, סיכום שבועי והיסטוריית שבועות.
- ממשק RTL רספונסיבי, גיבוי JSON, ותמיכת PWA בסיסית לשימוש אופליין לאחר טעינה ראשונה.
